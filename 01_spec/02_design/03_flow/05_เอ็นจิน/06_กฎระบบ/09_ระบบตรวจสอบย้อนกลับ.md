# 09_ระบบตรวจสอบย้อนกลับ — WM-Core_801
Traceability Layer  
การตามรอยข้อมูลตั้งแต่ต้นทาง → กลางทาง → ปลายทาง ของระบบ 801

---

## 1) วัตถุประสงค์ของ Traceability Layer
Traceability ใช้เพื่อ:
- ระบุต้นตอของข้อมูลทุกชิ้นในระบบ (origin tracking)  
- ตรวจสอบเส้นทางข้อมูลทั้งหมด (data lineage)  
- แก้ปัญหาเร็วเมื่อเกิด error หรือ anomaly  
- สร้างความโปร่งใสเพื่อการ audit  
- รองรับ compliance / PDPA / ระบบตรวจสอบภายนอก  

---

## 2) องค์ประกอบหลัก 4 ชั้น (Core Components)

### **Trace-01: Identity Marker (รหัสประจำตัวข้อมูล)**
ข้อมูลเข้าแต่ละชิ้นต้องมี:
- `trace_id` (unique-id)  
- `source`  
- `type`  
- `owner`  
- `origin_timestamp`  
- `hash(SHA256)`  
- `consent_flag` (ผ่าน PDPA หรือไม่)  

---

- Input Layer → Interpretation  
- Interpretation → Core Processor  
- Processor → IO Engine  
- IO Engine → Output  
- Output → End user / storage

### **Trace-03: Dependency Mapping (ความสัมพันธ์ของข้อมูล)**

## 3) การทำงานของ Traceability Pipeline

### **Step 1 — ติดแท็กข้อมูล (Tagging)**
ทุก input ต้องถูกแท็กด้วย `trace_id` ตั้งแต่เข้าระบบ  
ถ้าไม่มี → ปฏิเสธทันที

### **Step 2 — บันทึกการเคลื่อนที่ (Movement Logging)**
ทุกการเปลี่ยนสถานะของข้อมูล ต้องถูกบันทึกใน lineage log

### **Step 3 — แยก Parent/Child (Relationship Graph)**
ทำให้รู้ว่าข้อมูลสุดท้ายเกิดมาจากอะไร  
ช่วยย้อนแก้ปัญหาเร็วมาก

### **Step 4 — Validate Hash (Integrity Check)**
ทุกจุด checkpoint ต้องตรวจ hash ให้ตรงกัน  
ถ้าผิด → ถือว่า tampered

### **Step 5 — Export / Audit**
ระบบต้อง export log ออกเป็น:
- `.json`
- `.csv`
- `.md`

เพื่อส่งให้ auditor หรือ Custodian ใช้ตรวจสอบย้อนหลัง

## 5) การตรวจย้อนกลับ (Backtracking Rule)
เมื่อเกิด error ให้วิ่งย้อนตาม `trace_id` โดยลำดับ:

1) ตรวจ parent  
2) ตรวจ child  
3) ตรวจ lineage  
4) ตรวจ checkpoint  
5) ตรวจ hash  
6) ตรวจ origin metadata

ถ้าพบความผิดปกติ → isolate data → quarantine zone

---

## 6) มาตรฐานความปลอดภัย (Security Compliance)
Traceability ต้องครอบคลุม:
- PDPA  
- Chain-of-custody  
- Data lineage integrity  
- Zero trust validation  
- Evidence-grade timestamp  

ระบบต้องรองรับการ audit จากภายนอก (external verification)
