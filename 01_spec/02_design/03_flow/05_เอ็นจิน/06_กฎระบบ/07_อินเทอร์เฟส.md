# 07_อินเทอร์เฟส — WM-Core_801
Interface & I/O Interaction Rules  
ข้อกำหนดหน้าจอ และ การเชื่อมต่อ Input/Output ทั้งหมดของระบบ

---

## 1) เลเยอร์การรับข้อมูล (Input Layer UI)
หน้าจอที่รับข้อมูลต้องมีคุณสมบัติร่วมกันดังนี้:
- รองรับข้อความ (text)  
- รองรับเสียง (voice → ส่ง audio stream ไป IO Channel)  
- รองรับภาพ (image → base64 / binary)  
- ทุก input ต้องมี metadata กำกับเสมอ:
  - `source`
  - `type`
  - `intent`
  - `owner`
  - `timestamp`

> หมายเหตุ: UI ทุกแบบ **ห้ามส่งข้อมูลเปล่า (no raw)** ต้องผ่าน Filter ก่อนเสมอ

---

## 2) หน้าจอ AI Interpretation (Interpretation UI)
หน้าจอนี้ทำงานเฉพาะ:
- แปลงข้อความเป็น intent  
- แปลงเสียงเป็น transcript + emotion  
- แปลงรูปเป็นรายละเอียดที่ใช้กับ logic  
- ตีความความหมาย → ส่งไป Core Processor

องค์ประกอบหน้าจอ:
- กล่องวิเคราะห์ input  
- Emotion meter  
- Intent Summary  
- Confidence Score

---

## 3) Core Processor UI (Task Dispatcher Panel)
หน้าที่ของจอ:
- แสดงงานที่ AI จะแยกไปยัง Engine ต่าง ๆ  
- แสดง payload ที่ผ่านการตีความแล้ว  
- แสดงสถานะงานทั้งหมดแบบ Real-time

รายการงาน:
1) งานตอบข้อความ  
2) งานจัดการไฟล์  
3) งานประมวลผลเสียง  
4) งานสร้างภาพ/ข้อความ  
5) งาน IO (เชื่อม web / mobile / voice)

สถานะที่ต้องมี:
- `pending`
- `processing`
- `done`
- `error`

---

## 4) Logging Monitor UI (SystemLog Viewer)
การแสดงผล Log ต้องระบุ:
- `TASK_START`
- `TASK_END`
- `ERROR`
- `SYSTEM_CHECKPOINT`
- `IO_ACCESS`

คุณสมบัติสำคัญ:
- ค้นหา log ตาม user, time, event  
- โหลดย้อนหลัง ≥ 90 วัน  
- Export → `.json` / `.md`  

---

## 5) IO Channel Dashboard
ช่องทาง IO ทั้งหมดที่ระบบรองรับ:
- **web** → ข้อความ, ภาพ, ไฟล์  
- **mobile** → กล้อง, เสียง, ข้อความ  
- **voice** → สตรีมเสียงแบบ real-time  
- **cli** → คำสั่ง developer

Output Format ที่รองรับ:
- `json`
- `markdown`
- `image`  

Input Format:
- `text`
- `audio`
- `json`

---

## 6) PDPA UI Filter (Privacy First)
ตัวกรองนี้ต้องทำงานก่อนข้อมูลเข้า Interpretation Layer เสมอ:
- ลบข้อมูลอ่อนไหว  
- แทนที่ข้อมูลระบุตัวบุคคลด้วยรหัสแทน  
- ตรวจลึก metadata ก่อนส่งต่อ

ถ้าไม่ผ่าน → ระบบต้องเด้งแจ้งเตือนทันที

---

## 7) Error UI (แจ้งเตือนให้ผู้ใช้)
กรณีเกิดความผิดพลาด:
- error level 1 → แจ้งเตือนทั่วไป  
- error level 2 → แจ้งเตือน + แนะนำวิธีแก้  
- error level 3 → หยุดงาน → ส่งเรื่องให้ Custodian ตรวจสอบ  

องค์ประกอบหน้าจอ:
- Error Code  
- Description  
- Suggestion  
- Timestamp  
- User Context  

---

## 8) สรุป (Notes)
หน้าอินเทอร์เฟสทั้งหมดของ WM-Core_801 ใช้เพื่อให้ระบบรับ–ส่งข้อมูลได้อย่างถูกต้อง ปลอดภัย และตรวจสอบย้อนกลับได้  
UI ทุกตัวต้องผ่าน Filter และ Logging Layer ก่อนเข้ากระบวนการประมวลผลของ AI
